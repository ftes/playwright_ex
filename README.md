# PlaywrightEx

Elixir client for Playwright, being rebuilt as a 1:1 port of the official JavaScript client.
The public API is not there yet; see `PLAN.md`.

## Contributing

1. `mix setup` installs dependencies, the pinned Playwright driver and Chromium.
2. `mix test`, or `mix check` for everything CI runs.
